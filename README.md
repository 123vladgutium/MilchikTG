# MilchikTG — единый пакет обновления

## Что улучшено
- Единый SQL-файл для существующего проекта: `milchiktg-all-in-one.sql`. Запускается один раз целиком. Он создаёт/обновляет связанные таблицы и политики; это один скрипт, а не одна таблица (сообщения, профили и участники должны храниться раздельно для корректной работы).
- Исправлена проверка сообщений без текста, чтобы фотографии и голосовые не отклонялись ограничением `content`.
- Обновлены разрешённые типы медиа и Storage-политики для аватаров, фото и аудио.
- Более надёжная запись голосовых с выбором поддерживаемого MIME-типа и понятными ошибками.
- Контекстное меню сообщений: ПКМ на компьютере, нажатие на сообщении на телефоне; доступны редактирование, закрепление и удаление собственных сообщений.
- PWA: manifest, иконка и service worker; можно установить сайт на главный экран телефона/рабочий стол, если браузер поддерживает установку.

## ВАЖНО: перед обновлением
1. Сделай резервную копию SQL/данных, если в базе есть важные данные.
2. Открой текущий `script.js` на GitHub и сохрани значения `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY`.
3. Не используй `service_role`/secret key в браузере.

## Установка
1. Supabase → SQL Editor → New query → вставь весь `milchiktg-all-in-one.sql` → Run. Скрипт предназначен для текущего проекта, где уже существуют таблицы `profiles`, `conversations`, `conversation_members`, `messages`.
2. В `script.js` в начале вставь свои реальные `SUPABASE_URL` и publishable/anon key. В этом архиве ключи оставлены заглушками намеренно.
3. На GitHub загрузи в корень репозитория и замени: `index.html`, `style.css`, `script.js`; также добавь `manifest.webmanifest`, `icon.svg`, `sw.js`. Не удаляй остальные файлы проекта. Commit changes.
4. Подожди 2–5 минут и обнови сайт `Ctrl+Shift+R`. Если ранее был установлен PWA, закрой его и открой снова после обновления.
5. Для микрофона нужен HTTPS и разрешение браузера. На iPhone установка обычно делается через Safari → Поделиться → На экран «Домой».

## Возможные ограничения
Это расширенная браузерная версия мессенджера, не полноценная замена Telegram: нет звонков, сквозного шифрования, push-уведомлений гарантированных на всех платформах и продвинутой модерации. SQL-скрипт меняет схему и политики Supabase, поэтому проверяй результат в своём проекте.
