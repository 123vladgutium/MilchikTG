# MilchikTG 4.0 — Channel Studio

Обновлённый клиент MilchikTG на HTML, CSS и чистом JavaScript + Supabase. Фреймворки и Node.js для запуска сайта не нужны.

## Что добавлено

- Новый светлый интерфейс с более спокойной типографикой и компактными карточками.
- Обновлённая регистрация и вход; обновлены адреса CSS/JS и Service Worker cache, чтобы браузер не продолжал показывать старый дизайн.
- Аватары профиля, каналов и групп.
- Описание канала/группы и счётчик участников/публикаций.
- Роли `owner`, `admin`, `member`; владелец может назначать администраторов и снимать их, владелец/администратор может удалять участников с учётом ограничений.
- Публиковать в канале могут только владелец и администраторы; в группах сообщения доступны участникам.
- Подключение группы обсуждений к каналу.
- Комментарии привязаны к конкретной публикации, а не просто к общему чату.
- Счётчик прочтений каждой публикации на основе `message_reads`.
- Существующие функции: личные сообщения, поиск по имени/юзернейму, непрочитанные сообщения, отметки прочтения, фото, голосовые, закрепление/редактирование/удаление своих сообщений, профиль и PWA.
- Исправлен возврат из переписки на мобильном экране и очищается содержимое закрытого чата.

## Установка

1. Распакуй архив.
2. В `script.js` вставь свои настоящие `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY` в объект `CONFIG`. Используй только публичный anon/publishable key — никогда не вставляй `service_role` или secret key в браузерный код.
3. В Supabase открой **SQL Editor → New query** и выполни целиком `MilchikTG_FULL_DATABASE_ONE_FILE.sql`. Миграция не удаляет таблицы и сообщения; она добавляет поля ролей, настройки сообществ и комментарии.
4. Залей `index.html`, `style.css`, `script.js`, `sw.js`, `manifest.webmanifest`, `icon.svg` и SQL-файл в репозиторий GitHub Pages.
5. Подожди завершения GitHub Pages. Открой сайт и сделай полное обновление страницы. На телефоне закрой установленное PWA и открой снова; версия кэша поднята до v4.

## Как включить комментарии под постами

1. Создай группу и канал.
2. Открой канал и нажми `⋯`.
3. В настройках канала выбери существующую группу в поле **«Группа для комментариев под постами»** и сохрани.
4. Под постами появится кнопка комментариев. Читатель вступает в подключённую группу обсуждений при первом открытии комментариев; комментарий сохраняется именно для выбранного поста.

## Важные замечания

- Для новых функций обязательно выполнить SQL-файл. Одной загрузки фронтенда недостаточно.
- Функции проверяются политиками Supabase/RPC на сервере; скрытие кнопок в интерфейсе не используется как единственная защита.
- Счётчик прочтений показывает уникальных пользователей, для которых приложение сохранило запись прочтения. Это не считает анонимных посетителей и не является аналитикой просмотров до входа в аккаунт.
- Проверь конфигурацию Supabase Storage и Realtime, если фото, голосовые или обновления в реальном времени не работают.
