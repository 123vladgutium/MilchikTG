# MilchikTG — обновление фото, голосовых, прочтения и юзернеймов

Это обновление для уже работающего проекта MilchikTG. Оно сохраняет существующие таблицы, аккаунты, переписки и сообщения.

## Что исправлено и добавлено

- Фото в переписке открывается в полноэкранном просмотрщике по нажатию.
- Компоновка чата закрепляет нижнюю панель ввода и не даёт ей исчезать при отправке медиа.
- Голосовые отображаются с аудиоплеером и запасной ссылкой «Открыть аудио отдельно»; запись отправляется в чат, который был открыт при начале записи.
- Статусы собственных сообщений: «Отправлено» и «Прочитано».
- Счётчик непрочитанных сообщений возле чатов.
- Уникальные юзернеймы (3–24 символа: латиница, цифры и `_`). Уникальность проверяется на стороне PostgreSQL без учёта регистра, поэтому два пользователя не смогут занять `test` и `TEST` одновременно.

## Установка

### 1. Выполнить миграцию Supabase один раз

1. Открой Supabase → SQL Editor → New query.
2. Открой `supabase-upgrade-read-status-username.sql`.
3. Скопируй весь код, вставь в новый запрос и нажми Run.
4. Не удаляй существующие таблицы и данные. Не нужно повторно запускать старый all-in-one SQL.

Миграция добавляет поле `profiles.username`, уникальный индекс и таблицу `message_reads`. Таблица `message_reads` нужна для статусов прочтения и счётчиков непрочитанных.

### 2. Обновить файлы на GitHub Pages

Загрузи в корень существующего репозитория с заменой старых файлов:

- `index.html`
- `style.css`
- `script.js`

Также добавь/обнови `manifest.webmanifest`, `icon.svg`, `sw.js`, если они отличаются от текущих.

**Важно:** перенеси настоящие `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY` из текущего `script.js` в обновлённый файл. Не вставляй `service_role`/secret key в публичный JavaScript.

### 3. Проверить

1. Открой сайт с принудительным обновлением (`Ctrl + Shift + R`).
2. В настройках профиля задай юзернейм. Если он занят, сайт покажет сообщение; база сама не позволит дублировать его.
3. Открой чат со второго аккаунта, отправь текст и проверь «Прочитано».
4. Отправь сообщение в другой чат, не открывай его и проверь счётчик непрочитанного.
5. Нажми на фото, чтобы открыть его крупно; проверь голосовое на обоих аккаунтах.

## Примечания

- Статус «Прочитано» появится, когда получатель откроет чат и запись о прочтении сохранится в базе.
- Счётчик показывает непрочитанные сообщения, которые доступны текущему аккаунту в его чатах.
- Для голосовых требуется поддержка `MediaRecorder` браузером и доступ к микрофону. Если старые голосовые были загружены в неподдерживаемом формате, новые исправления не перекодируют их автоматически.
- Я не могу проверить вашу реальную Supabase-базу из этого архива. Если миграция покажет ошибку, не удаляй таблицы: сохрани текст ошибки и проверь его перед повторным запуском.
