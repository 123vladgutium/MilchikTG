# MilchikTG — улучшенная версия мессенджера

Это **предыдущая версия MilchikTG (мессенджер)** с обновлённым оформлением. Это не версия социальной сети с лентой публикаций.

## В этой версии
- Личные переписки, группы и каналы из предыдущего проекта.
- Отправка текста, фотографий и голосовых сообщений.
- Редактирование, удаление и закрепление сообщений через меню действий.
- Профили и загрузка аватара.
- Настройки оформления, приватности и уведомлений.
- PWA: установка на главный экран/рабочий стол, если браузер поддерживает установку.
- Обновлённый тёмный интерфейс, мобильная адаптация и более чёткие состояния кнопок/панелей.

## Установка на существующий проект
1. Сохрани резервную копию текущих файлов.
2. Перед заменой `script.js` скопируй из своего рабочего файла реальные `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY`.
3. Вставь эти два значения в начало нового `script.js`. Не вставляй `service_role` или secret key в публичный код.
4. На GitHub замени `index.html`, `style.css`, `script.js`; добавь/обнови `manifest.webmanifest`, `icon.svg`, `sw.js`.
5. Не запускай SQL повторно, если база данных уже работает с этой версией и не менялась схема. Файл `milchiktg-all-in-one.sql` включён как справочный/установочный для предыдущего пакета, а не как обязательный шаг для одного лишь обновления дизайна.
6. Сделай Commit changes, подожди публикацию и обнови сайт через Ctrl+Shift+R.

## Важно
Это браузерный мессенджер, а не полноценная замена Telegram. Поддержка медиа зависит от настроек Supabase Storage и разрешений браузера. Не публикуй секретные ключи.
